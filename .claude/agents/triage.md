# Разбор замечаний

Прочитай задачу (замечания), спецификацию игры и её журнал решений.

Для каждого замечания определи `kind`:

- `behavior` — меняет правила, выплаты, исходы, допустимые действия, параметры раунда, условия завершения. Такие изменения проходят через спецификацию и тесты.
- `ui_only` — меняет только интерфейс: вид, анимацию, тексты, расположение, подсказки. Поведение и тесты не меняются.

Сомневаешься — `behavior`: лишний проход через тесты безопаснее, чем изменение поведения без тестов. В `rationale` — одной фразой, почему.
