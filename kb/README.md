# База знаний

Уроки прошлых запусков: проблема, причина, правило. Записи `KB-NNN-*.md` создаёт и обновляет оркестратор по итогам ретроспективы (агент `librarian`); человек их не редактирует. Перед каждым этапом оркестратор передаёт агенту записи, помеченные его ролью, а агент указывает применённые в `applied_kb` — это видно в отчёте запуска.
