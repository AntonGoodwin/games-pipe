# tests: done

Написал в platform/tests/ приёмочные тесты для всех 24 сценариев. На каждый сценарий есть минимум один тест с ID в названии.

Файлы:
- wallet.test.ts — PL-1…6, кошелёк по HTTP, временный dataDir;
- rounds.test.ts — PL-7…20, движок раундов через testkit;
- core-http.test.ts — PL-21…23, ядро и кошелёк по HTTP, перезапуск, автоподключение игр из временного gamesDir;
- sdk.test.ts — PL-24, happy-dom; /sdk.js берётся с запущенного ядра, fetch подменён записывающей обёрткой;
- helpers.ts — общие помощники;
- fixtures/ — тестовые игры t-flip и t-steps: manifest, server/index.js, ui.

Тесты проверяют точные суммы, балансы до и после, состав и число транзакций, HTTP-статусы и коды ошибок. Отдельно проверяется:
- порядок проверок: игра → лимиты → параметры → открытый раунд → кошелёк, при этом rng не расходуется при отказах;
- округление к ближайшему центу и до проверки лимитов, в обе стороны;
- secret не раскрывается до закрытия раунда;
- повторная выплата не проходит, конфликт txId, сохранность данных после перезапуска.

Чего нет на диске, подключается динамическим импортом через переменную, а фикстуры написаны на .js. Причина: на этапе coverage запускается tsc по platform/**/*.ts, а реализации пока нет.

Ограничение: команды в этом запуске запрещены, поэтому ни tsc, ни vitest я не запускал. Типы проверил только вручную. Сейчас все тесты падают на загрузке, потому что модулей платформы ещё нет.
