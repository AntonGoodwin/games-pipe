R-1. Кошелёк теперь пропускает запрос только при выполнении всех условий:
- заголовок Host локальный;
- заголовка Origin нет, иначе 403 FORBIDDEN;
- тело POST имеет тип application/json, иначе 415;
- если задан `token`, в заголовке `x-wallet-token` передан верный секрет, иначе 401 UNAUTHORIZED. Секрет сравнивается за постоянное время.

`start.ts` создаёт секрет через crypto.randomUUID() и передаёт его в `startWallet({ token })` и `startCore({ walletToken })`. Клиент кошелька отправляет этот секрет в каждом запросе. Без `token` кошелёк работает как раньше, поэтому тесты не затронуты. Проверки Host и типа тела вынесены в `shared/http.ts` (`checkLocalHost`, `checkJsonBody`). Добавлен код ошибки UNAUTHORIZED.

R-2. Ядро для всех `/api/*` принимает только Host вида localhost, 127.0.0.1 или [::1] (а также адрес прослушивания, если он не 0.0.0.0 или ::) с фактическим портом сервера. Иначе ответ 403. Проверка Origin против Host осталась после неё. Кошелёк проверяет Host так же.

R-3. Если кошелёк окончательно отклонил досылку выплаты (это не сбой связи), `open()` больше не падает. Ошибка пишется в лог с пометкой «нужен ручной разбор». Ответ содержит лимиты, баланс и `activeRound` с `view: null`; у раунда, ждущего выплаты, `view` всегда `null`. `startRound` и `action` для такой игры по-прежнему отвечают INTERNAL_ERROR, пока раунд не разобран вручную.
