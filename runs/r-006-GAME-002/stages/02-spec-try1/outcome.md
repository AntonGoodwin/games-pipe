# spec: done

Готова спецификация games/mines/spec.md для «Мин». Поле 5×5, 3 мины. Мины расставляются в start частичной тасовкой Фишера — Йетса: ровно 3 вызова rng, action к rng не обращается. Ходы: { type: "reveal", cell } и { type: "cashout" }. Множитель: M(k) = round2(0.98 × C(25,k)/C(22,k)), выплата = bet × M(k). В спеке есть таблица контрольных значений M(k). publicView не раскрывает мины, пока раунд открыт. Лимиты, кошелёк и округление даны ссылкой на platform/spec. 15 сценариев с точными ставками, значениями rng, выплатами и балансами. Отдельные сценарии: обе границы rng при расстановке, автозавершение после 22 безопасных клеток, недопустимые ходы, cashout при k=0, закрытый раунд, params, лимиты, недостаток средств, обновление страницы, контракт модуля (число вызовов rng, неизменяемость state, сериализуемость) и интерфейс. Таблицу множителей и расстановки мин посчитал вручную: запуск скрипта был запрещён (don't ask mode).
