# learn: done

Запуск GAME-002 «Мины» прошёл гладко: каждый этап с первой попытки, споров по тестам, откатов записи и остановок не было. Новых проблем нет, поэтому записываю два урока. 1) Обновляю KB-006: шаблон спецификации работает и для многоходовых игр. Rng вызывается только в start, фиксированное число раз, action детерминирован, в спеке есть таблица контрольных значений множителя, а секрет скрыт в publicView. 2) Новая запись по замечанию ревью R-1 (minor). После ROUND_CLOSED, ROUND_NOT_FOUND или WALLET_UNAVAILABLE интерфейс застревает в состоянии playing. Это поведение нужно закладывать в спецификацию и интерфейс любой игры заранее, чтобы оно не всплывало в каждой игре заново. Допущение: «попытка 1» у агентских этапов и «попытка 0» у проверок означают первый проход.
