# learn: done

Запуск r-003-PLAT-001 остановился на этапе docs. Документация была в порядке, но docs_check оба раза падал на одной и той же ссылке [[runs/r-003-PLAT-001/report]] в файле задачи. Эту ссылку оркестратор сам пишет в журнал при старте запуска (factory/run.ts:285), а report.md создаёт только в конце (writeReport, :324). Проверка brokenWikiLinks (factory/lib/checks.ts:215) включает файл задачи, поэтому падает при каждом запуске, а агенту docs этот файл недоступен для записи. Обе попытки docs ушли впустую. Заведена новая запись о дефекте оркестратора и о том, как отличать сбой проверки от ошибки агента. KB-004 дополнена замечанием R-1 из ревью: обёртка rng должна переставать работать после выхода из start/action. Допущение: исправление в factory/ (заглушка report.md при старте или исключение ссылки на отчёт текущего запуска) делает мейнтейнер фабрики, а не агенты этапов.
