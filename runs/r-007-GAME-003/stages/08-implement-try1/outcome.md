# implement: done

Внёс в «Мины» все четыре замечания GAME-003. Все 49 тестов проходят (module 17, rounds 24, ui 8), `pnpm exec tsc --noEmit -p tsconfig.json` прошёл без ошибок.

Сервер (`games/mines/server/index.ts`):
- params теперь `{ mines }`, целое число от 1 до 24, по умолчанию 3. Типы не приводятся, лишние поля отбрасываются. Проверку делают и `validateParams`, и `start`, оба до первого обращения к rng.
- Мины расставляются частичной тасовкой Фишера — Йетса ровно за m вызовов rng.
- Множитель считается по формуле `Math.round(98 × C(25,k) / C(25−m,k)) / 100` на целых биномиальных коэффициентах.
- Число мин `action` и `publicView` берут только из `state.mines.length`. Раунд завершается сам после 25 − m безопасных клеток.
- Константы `MINE_COUNT`, `SAFE_COUNT` и `RTP` удалены. Вместо них `MIN_MINES`, `MAX_MINES`, `DEFAULT_MINES`, `RTP_PERCENT` и `multiplier(k, mineCount)`.

Интерфейс (`games/mines/ui/index.html`):
- Добавлен выбор числа мин `<select data-testid="mines-input">` с вариантами 1…24. В `playing` он заблокирован, при восстановлении раунда берёт `view.mineCount`, в `startRound` уходит числом.
- На кнопке показывается «Забрать $X» от ставки раунда.
- В конце раунда клетки получают состояния `mine` (нейтральный фон), `hit` (красный) и `safe` (зелёный).
- Открытая клетка переворачивается за 250 мс (`rotateY`). Состояние клетки выставляется сразу по ответу, анимация его не задерживает.
- При `ROUND_CLOSED`, `ROUND_NOT_FOUND` и `WALLET_UNAVAILABLE` интерфейс пересинхронизируется через `sdk.open()`. Остальные коды только показываются игроку.
