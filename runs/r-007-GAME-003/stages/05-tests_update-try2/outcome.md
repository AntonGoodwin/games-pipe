Исправил ошибку tsc в games/mines/tests/module.test.ts. Тест импортировал модуль с типом, который объявила сама игра: GameModule<MinesParams, …>, где в текущем коде MinesParams = Record<string, never>. Поэтому params { mines: N } из новой спецификации не проходили проверку типов. Теперь модуль импортируется как gameModule и приводится к общему контракту платформы: `const game = gameModule as unknown as GameModule` (import type из platform/sdk/types.ts, это совместимо с verbatimModuleSyntax и erasableSyntaxOnly). Проверки и ожидаемые значения не менялись, поведение тестов осталось прежним. rounds.test.ts и ui.test.ts ошибок tsc не давали и не менялись. Bash запрещён, поэтому tsc и vitest я не запускал.
