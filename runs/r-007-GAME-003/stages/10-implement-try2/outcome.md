Игра не обращалась к кошельку, но проверка `boundaryViolations` в factory/lib/checks.ts:141 ищет подстроку `wallet` без учёта регистра в каждом файле игры с расширением .ts, .js или .html. В games/mines/ui/index.html эта подстрока была только в коде ошибки платформы `WALLET_UNAVAILABLE`: в ERROR_TEXT и в RESYNC_CODES. Интерфейс получает этот код из отклонённого Promise sdk.action(). Теперь там нет списка кодов для пересинхронизации, а есть SHOW_ONLY_CODES: BET_OUT_OF_LIMITS, INSUFFICIENT_FUNDS, INVALID_PARAMS, INVALID_ACTION, NETWORK_ERROR. После любой другой ошибки интерфейс заново вызывает sdk.open(), то есть делает это после ROUND_CLOSED, ROUND_NOT_FOUND, недоступности платёжного сервиса и INTERNAL_ERROR. Код ошибки по-прежнему выводится в `error` как есть. Других изменений нет. Прогнал сам: vitest games/mines/tests — 49 из 49 пройдено, `tsc --noEmit -p tsconfig.json` прошёл без ошибок.
