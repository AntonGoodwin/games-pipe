# implement: done

Игра «Монетка» сделана, все 16 заблокированных тестов проходят, `tsc --noEmit` без ошибок, оба прогона я сделал сам. Сервер (`games/coin/server/index.ts`): `validateParams` принимает только объект, где `side` равен ровно `heads` или `tails`, и возвращает `{ side }`, лишние поля отбрасываются. `start` ещё раз проверяет параметры и только после этого один раз вызывает `rng.next()`: если число меньше 0.5, выпал орёл, иначе решка. Выплата при угадывании — ставка × 1.96, при проигрыше 0, раунд закрывается сразу. Округление до центов делает платформа. `action` всегда бросает `INVALID_ACTION` и не обращается к rng. `publicView` отдаёт `{ side, outcome, win }`. `Math.random` не используется, из платформы импортируется только `platform/sdk/types.ts`. Интерфейс (`ui/index.html`) работает только через `window.PlatformSDK`. На странице есть все `data-testid` из спеки, а у корневого элемента `data-testid="game"` атрибут `data-state` принимает значения `idle`, `playing`, `won` и `lost`. Пока запрос в пути, кнопки заблокированы. Ошибка платформы показывается кодом и текстом на русском, баланс при этом не меняется. Лимиты ставки приходят из `open()`; если `open()` вернул незакрытый раунд, страница его показывает.
