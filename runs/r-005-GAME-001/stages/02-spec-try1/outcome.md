# spec: done

Написан games/coin/spec.md. Игра «Монетка»: один бросок за раунд, params { side: "heads" | "tails" }. Исход определяется одним числом rng: r < 0.5 даёт heads, иначе tails. При угадывании выплата bet × 1.96, при проигрыше 0. Раунд закрывается прямо в start, publicView = { side, outcome, win }. Лимиты, кошелёк и округление описаны ссылкой на [[platform/spec]]. Сценарии SC-1…SC-11 на Gherkin с конкретными ставками, значениями rng, выплатами и балансом. Они покрывают: выигрыш и проигрыш, обе границы rng (0.4999 и 0.5), округление (3.33 → 6.53), неверные params (отклоняются до списания и до обращения к rng), один сценарий на лимиты, один на недостаток средств, серию раундов с ROUND_CLOSED и activeRound: null, контракт модуля (rng вызывается ровно 1 раз, состояние сериализуется, action → INVALID_ACTION) и интерфейс через подменённый PlatformSDK.
