# tests: done

Я написал приёмочные тесты для «Монетки» в трёх файлах в games/coin/tests: rounds.test.ts (сценарии SC-1…SC-9 через createTestPlatform и fixedRng), module.test.ts (SC-10, прямые вызовы серверного модуля) и ui.test.ts (SC-11, happy-dom с подменённым window.PlatformSDK). На заглушке 15 из 16 тестов падают ожидаемо: NOT_IMPLEMENTED, INTERNAL_ERROR, нет элементов интерфейса. Проходит только SC-7 (отказ по лимитам ставки делает платформа, это допустимое исключение). tsc ошибок не выдаёт. Сверить тесты с эталонной реализацией не удалось: запуск такой проверки из scratchpad был запрещён, поэтому проверено только падение на заглушке.

Какие ошибки ловят тесты:
- **Суммы.** Сверяются точные выплаты (1.96, 19.6, 0, 3.92, 6.53, 9.8), баланс после раунда и полный журнал транзакций: тип, сумма и balanceAfter.
- **Граница исхода.** Проверяется с обеих сторон: 0.4999 даёт орла, 0.5 даёт решку. Неверное сравнение (`<=` вместо `<`) или перепутанные стороны тест поймает.
- **Неверные params.** Отклоняются до списания и не расходуют rng: после шести отказов единственное число 0.3 должно достаться следующему корректному раунду.
- **Один вызов rng.** В серии раундов fixedRng кончится, если игра возьмёт лишнее число. В SC-10 считается число вызовов, а `action` должен отказывать, не трогая rng.
- **Лишние поля.** Поле `extra` не должно попасть в view.
- **Math.random.** Подменён на функцию, которая бросает ошибку, так что его использование сразу уронит тест.
- **Интерфейс.** Проверяются переходы idle → playing (кнопка заблокирована, исход ещё не показан) → won. Ставка должна уходить числом 1, а не строкой. При отказе код ошибки появляется в `error`, баланс не меняется, кнопка снова доступна.
